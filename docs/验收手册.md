## 第9步：红线核验

**9.1 Schema 冻结**

「规则详情/编辑」→ 编辑任意规则 → 在 JSON 里**新增一个未知字段**（如 `"hack_field": 1`）→ 保存

详细操作：
1. 双击「shortcuts」→「启动网页」，导航到「规则详情/编辑」；
2. 选择任意一条规则，点「✏️ 编辑此规则」；
3. 在「结构化规则 JSON」里找到 `"rule_id": "R...",` 这一行，下一行插入 `"hack_field": 1,`（插在两个字段之间时行尾要有英文逗号）；
4. 点「保存修改」→ 应出现红色报错「保存失败：JSON 不合法或不符合 Rule Schema」（`extra=forbid` 拦截），规则数据未被改动；
5. 删掉 `"hack_field": 1,` 那行再保存，恢复正常。

预期：保存失败，提示「不符合 Rule Schema」（`extra=forbid` 拦截），字段结构零漂移。

☐ 通过

**9.2 LLM 边界**

回顾本验收中所有「🤖 AI 解释/说明」按钮的输出：全部是**对已有结构化结果的翻译**，没有一个按钮会改变规则数据、冲突列表、推演结果或统计数字。

☐ 通过

**9.3 沙箱隔离**

推演任意样本前后，`cli.py stats` 的规则/冲突/版本数字均不变（仅「沙箱推演次数」+1）。

☐ 通过
